# Contributing

Contributions that improve reproducibility, source accuracy, statistical methods, accessibility, provenance and error correction are welcome.

Please open an issue describing the proposed change before submitting substantial work.

Do not submit:

- personal data;
- credentials or API keys;
- unpublished allegations about identifiable people or businesses;
- copyrighted source datasets that cannot legally be redistributed;
- claims of causation or illegality unsupported by appropriate evidence.
