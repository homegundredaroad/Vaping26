# Public provenance

This directory receives publication provenance generated by the private research pipeline after disclosure and public-release checks.

Expected generated files include:

- `publication_manifest.json` — SHA-256 and byte-size manifest for generated public files.
- `source_register.json` — public-safe catalogue of registered evidence sources and their roles.
- `source_coverage.json` — public-safe record of which sources were attempted and their run status.

Raw source data, credentials, private query strategies and unresolved investigations are intentionally excluded from this repository.
