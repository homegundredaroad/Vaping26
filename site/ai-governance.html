AI governance

AI may assist evidence processing. It does not get the final scientific word.

Vaping26 uses automation to improve coverage and structure, but conclusion-sensitive scientific judgements remain behind provenance, deterministic validation and human-review gates.

Core ruleAI-assisted output is a candidate extraction or classification, not a health conclusion. No automated step may promote a record into conclusion-sensitive synthesis without the required governed review state.

Permitted assistance

  • Candidate metadata extraction where source licensing permits.
  • Study-design or topic triage with explicit uncertainty and abstention.
  • Identifier matching and record reconciliation.
  • Structured field suggestions tied to source provenance.
  • Detection of records that need human attention.

Not permitted autonomously

  • Declaring causation, safety, diagnosis, illegality or criminality.
  • Inventing outcomes, effect estimates or comparator data.
  • Assigning risk-of-bias judgements as if human reviewed.
  • Converting publication counts into health-effect claims.
  • Overriding missing or unresolved evidence with a guess.

Controls against hallucination and silent error

Source grounding

Conclusion-sensitive fields must be traceable to an identifiable source. Unsupported generated text is not treated as evidence.

Schema validation

Machine-assisted outputs must satisfy deterministic field and state constraints before publication.

Human review

A candidate record remains unreviewed until a governed human-review state is recorded. Automation cannot self-certify review completion.

Abstention

Unknown and unresolved states are preserved. The system is designed to say “not yet established” rather than force a classification.

Release provenance

Public releases carry source coverage, release provenance and SHA-256 publication manifests so outputs can be tied back to a particular research run.

Correction

If an extraction or classification is found to be wrong, the corrected governed record is republished in a later release rather than silently rewritten as historical truth.

Where humans enter

The intended chain is: registered source → harvest → validation → deduplication → candidate evidence record → source-grounded extraction → human review → risk/quality review → question-specific synthesis → publication gate.

Collection is not synthesis, and automated classification is not scientific review.
