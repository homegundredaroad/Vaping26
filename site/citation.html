Citation

How to cite Vaping26.

Citations should identify the project and, whenever a result or dataset is used, the specific public release being consulted. Vaping26 is an independent SCC Nexus evidence-infrastructure project and does not claim institutional sponsorship or academic endorsement.

Project citation

SCC Nexus. Vaping26: UK Vaping & Nicotine Evidence Observatory. Independent evidence-monitoring infrastructure for vaping and nicotine research and official UK data. Cite the public observatory together with the date accessed.

The repository now includes a machine-readable CITATION.cff file so citation managers and archival services can identify the project consistently.

Release citation

Vaping26. UK Vaping & Nicotine Evidence Observatory. Public evidence release. Include the approved export timestamp, research run identifier and code revision shown in the release provenance for the version consulted.

Dataset citation

When using a machine-readable dataset, cite the dataset name, Vaping26 as publisher, the approved public-release timestamp and the exact file path. Retain the accompanying publication manifest hash where reproducibility matters.

ImportantA candidate evidence record is not a completed scientific review. Citation of a Vaping26 record should not be presented as Vaping26 endorsing the underlying study or its conclusions.

Authorship and affiliation

SCC Nexus is the project owner/publisher. Research contributors and external reviewers should be identified separately where named, so project ownership, contribution and independent review are not conflated. External review does not imply institutional sponsorship or endorsement.

Individual evidence records

For an individual record, cite the original PMID, DOI or source record as the primary scientific source. Vaping26 may additionally be cited for its structured mapping, review state and provenance metadata.
