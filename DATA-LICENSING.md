# Data licensing

The repository software is distributed under the repository's MIT licence. That licence does not automatically apply to third-party source data.

Each published dataset must record its source and, where known, its applicable licence or reuse terms. Vaping26 should publish derived or redistributed data only where the source terms permit it.

Where redistribution is restricted, the public project should publish metadata, citations, reproducible retrieval instructions or aggregate findings instead of republishing restricted source material.
